# Digital Closet App

A playful digital closet web app where users can upload clothing photos, tag items by category, roll a random outfit, save looks they like, and sign in with JWT-based auth.

## Features

- Upload clothing photos from your device
- Preview images instantly before saving them to the closet
- Tag items as tops, bottoms, shoes, outerwear, or accessories
- Filter the closet feed by category
- Generate one random outfit from saved pieces
- Save favorite generated looks
- Sign up and sign in with email/password
- JWT authentication stored in an HTTP-only cookie
- Closet state stored per authenticated user in browser storage

## Run Locally

Install dependencies:

```bash
npm install
```

Start the server:

```bash
npm start
```

Then open:

```text
http://127.0.0.1:4173
```
